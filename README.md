# ⚖️ Website - Advocacia Tributária

Website institucional desenvolvido para um escritório de advocacia com atuação na área tributária.

O projeto tem como objetivo apresentar os profissionais, áreas de atuação e serviços jurídicos de forma clara e acessível, além de facilitar o contato com o escritório.

> 🚧 Projeto em desenvolvimento.

## 💻 Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## ⚙️ Funcionalidades atuais

- Página institucional do escritório
- Apresentação das principais especialidades tributárias
- Seção "Sobre Nós"
- Apresentação dos profissionais
- Carrossel de imagens
- Integração para contato via WhatsApp
- Layout responsivo em desenvolvimento

## 📌 Áreas apresentadas no site

Entre as áreas exibidas estão:

- Execuções Fiscais
- Planejamento Tributário
- Imunidades e Isenções
- Revisão de IPTU e ITBI
- Recuperação de Créditos Tributários
- Transação e Parcelamento Fiscal
- Tributos Municipais, Estaduais e Federais

## 🚧 Status do projeto

O website ainda está em desenvolvimento.

Entre as próximas etapas estão melhorias de responsividade, navegação, organização do código e finalização das seções do site.

## 🎯 Objetivo

Este projeto foi desenvolvido como uma aplicação prática dos meus conhecimentos em desenvolvimento Front-end, utilizando HTML, CSS e JavaScript em um projeto voltado para uma necessidade real.
